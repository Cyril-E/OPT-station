Comment recevoir les alertes ?

Utilisez HTTPS, autorisez les notifications dans Chrome et dans les réglages du système, puis gardez un onglet OPT Station ouvert. Les caméras ne sont pas chargées pour surveiller les alertes.

Une impression annulée, une erreur ou une perte de connexion ne vaut pas une fin réussie. Une pause ou un état d’intervention déclenche une alerte; le motif précis dépend des informations fournies par PrusaLink.

Si Chrome met l’onglet en veille, ajoutez l’adresse de la station aux sites à toujours garder actifs. Aucun événement ancien n’est rejoué après reconnexion; les alertes s’arrêtent lorsque tous les onglets OPT Station sont fermés.

Points de retour locaux

Chaque restauration conserve l’état précédent sur le Pi. Choisissez un point pour le vérifier et revenir à cet état.

Sauvegardes automatiques planifiées

Choisissez un disque externe ou un partage réseau déjà monté sur le Pi. Si le support est absent, aucune sauvegarde ne sera créée sur le disque système.

Une clé privée est conservée sur le Pi pour chiffrer les sauvegardes sans intervention. Elle n’est pas incluse dans les fichiers exportés. Gardez votre mot de passe pour les restaurer. Laissez ce champ vide pour conserver le mot de passe enregistré.

Les identifiants PrusaLink et caméra sont inclus dans les sauvegardes de configuration. Le système du Pi, ses accès Wi-Fi et les préférences propres au navigateur ne sont pas sauvegardés.

Ce que les IA peuvent faire

Une fois le MCP activé et ajouté à un client compatible, votre assistant peut :

  • Consulter et rechercher les bobines du stock, leurs dates d’entrée, leur identification QR ou RFID et les quantités restantes connues.
  • Consulter les favoris et les modèles de bobines de votre bibliothèque.
  • Lire le carnet commun et les notes de chaque bobine, et retrouver une bobine par son numéro B0000.
  • Créer, modifier et supprimer des favoris ou modèles réutilisables pour préparer vos futures bobines.

Ces fiches apparaissent dans Inventaire → Vos favoris et modèles. Les écritures RFID, l’impression d’étiquettes, les réglages privés et l’alimentation du Pi restent dans OPT Station.

Le MCP donne ces accès aux clients qui peuvent joindre la station sur votre réseau local, sans code supplémentaire. Il ne connecte pas automatiquement un compte IA et ne synchronise pas la consommation Prusa Connect.

Vérification des versions GitHub

Quand elle est activée, la station consulte les versions publiées à l’intervalle choisi et au redémarrage si une vérification est due. Les brouillons et les simples tags Git ne sont pas proposés.

Les numéros de version sont comparés dans leur ordre réel : 0.10 est plus récent que 0.9. Le choix Inclure les préversions permet de voir les publications de test.

Pour un dépôt privé, créez un jeton GitHub à permissions fines, sélectionnez uniquement le dépôt concerné et accordez Contents : Read-only. Saisissez-le dans ce formulaire, jamais dans une conversation. Le jeton reste sur le Pi et n’est jamais renvoyé au navigateur.

Créer un jeton GitHub à permissions fines

Le jeton est inclus dans les sauvegardes de configuration, avec ou sans mot de passe selon votre choix. En cas de panne réseau, la dernière version connue reste indiquée avec la date du dernier contrôle réussi. Une erreur ne signifie jamais que la station est à jour.

Cette fonction ne télécharge pas les fichiers de la release et ne remplace aucun logiciel, réglage, stock ou tag RFID. Le lien GitHub permet de consulter la nouvelle version et son mode d’installation.
